### Приложение "Спектр+" для детей с РАС и их родителей

Запуск:

1. Скачать архив или склонировать репозиторий на личный компьютер. Рекомендуется запускать приложение в Android Studio.

2. Запустить сервер, который находится в папке backend. Это можно сделать с помощью IntelijIdea, открыв в ней проект, выбрав конфигурацию и нажав на стандартную кнопку запуска проекта, а также любым другим удобным способом компиляции Java-кода.

3. Запустить мобильное приложение с помощью Android Studio, выбрав устройство-эмулятор и нажав на стандартную кнопку запуска приложения.
